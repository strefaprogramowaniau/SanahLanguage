# SanahLanguage
Hobbystyczny projekt we wczesnej fazie języka programowania ogólnego zastosowania 
#Inspiracja nazwy (Etymologia)

Nazwa SanahLanguage wywodzi się od japońskiego sufiksu honoryfikatywnego *-san* oraz zainteresowania twórcy kulturą japońską, a także od wyrażenia *ah*, rozumianego jako westchnienie. Połączenie tych elementów tworzy człon **san-ah**, zapisywany jako **Sanah** w celu uproszczenia i estetyzacji zapisu.

Nazwa została przyjęta jako element konwencji artystycznej i humorystycznej projektu. Projekt ma charakter fanowski, eksperymentalny i dydaktyczny oraz nie jest przedstawiany jako projekt oficjalnie związany z jakąkolwiek osobą, artystą, organizacją lub podmiotem zewnętrznym.

Twórca przyjmuje również założenie etyczne, zgodnie z którym przypadkowe podobieństwo nazwy do istniejących oznaczeń nie powinno być wykorzystywane do przypisywania projektowi charakteru, którego nie posiada, ani do sugerowania nieistniejącego związku z podmiotem trzecim.

Powyższa nota opisuje wyłącznie genezę i kontekst przyjęcia nazwy i nie stanowi twierdzenia o zakresie ochrony prawnej poszczególnych oznaczeń.
